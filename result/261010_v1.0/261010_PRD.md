## 1. [본 - 本질] 사용자의 본질적 요구 파악
- **자연어 요청**: "SK하이닉스의 AISK대비하자 이것도 반도체3구성과 동일하게 구성해줘. 그리고 반도체2는 아예지워버리자. 이제안씀. 1분 30초 수준의 답변을 너가 만들어야하고 인성질문과 직무질문으로 나누고 각각 일단 20개씩 채워줘 직무질문은 저 위에 질문과 비슷한 난도와 수준으로 내줘"
- **본질 파악**:
  SK하이닉스 양산기술/소자/공정 실전 합격을 위해, **인성 역량(20문항)과 반도체 기술 역량(20문항) 총 40문항**을 엄선하여, **1분 30초 구어체 실전 전달(약 380~450자) + 세부 마스터 강의 노트 + KaTeX 수식 + 고품질 SVG 다이어그램**이 완비된 '반도체3'급 반응형 웹 대시보드 및 마스터 문서를 원클릭 자동 배포 파이프라인으로 구축하는 것.

## 2. [기 - 機能] 기능적 스펙 및 입출력 정의

### (1) 엔지니어링 기능 명세
| 기능 ID | 기능명 | 세부 명세 |
| :--- | :--- | :--- |
| **F-01** | 카테고리 듀얼 탭 시스템 | `전체(40)`, `인성 역량(20)`, `직무·기술 역량(20)` 3단계 카테고리 필터 칩 지원 |
| **F-02** | 1분 30초 실전 전달 프레임 | 모든 문항에 실제 1분 30초 동안 구어체로 완벽히 소화할 수 있는 글자 수(380~450자) 최적화 답변 탑재 |
| **F-03** | 심층 마스터 강의 노트 | 배경 지식, 공학적 수식(KaTeX), 인성/행동 분석 프레임워크(STAR/VWBE) 심층 해설 |
| **F-04** | 고품질 반응형 SVG 도감 | 반도체 물리 구조 및 인성 소통 프로세스를 직관적으로 표현하는 풀컬러 벡터 SVG 렌더링 |
| **F-05** | 좌측 서랍식 네비게이션 | 40개 문항 실시간 검색(Search) 및 모바일/PC 반응형 서랍 토글(Collapse) 지원 |
| **F-06** | 1분 30초 타이머(Stopwatch) | 연습 시 1분 30초를 시각적으로 카운트다운/체크할 수 있는 실전 타이머 위젯 탑재 |
| **F-07** | 원클릭 빌드 & 배포 | `run.bat` 실행 시 context 데이터를 기반으로 대시보드 자동 갱신 및 브라우저 즉시 기동 |

### (2) 문항 구성 (총 40문항)
1. **인성 질문 20문항**:
   - 직무 적합 이유, 피드백 갈등 해결, 무임승차자 대처, 원칙 vs 팀 충돌, 실패 극복, VWBE 한계 돌파, 상사의 비합리적 지시 대처, 일정 vs 품질 트레이드오프, 부서 간 이해대립 조율, 치명적 단점 극복, 단순 반복 업무 마인드셋, 스트레스 관리, 단기간 기술 습득, 돌발 위기 대응, 성향 반대 동료 협업, 성과 부진 극복, 윤리적 딜레마, 주변의 평가, VWBE 실천 사례, 3~5년 후 성장 비전.
